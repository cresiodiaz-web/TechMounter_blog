# TechMounter Blog

Blog técnico especializado em manufatura eletrônica, qualidade, melhoria contínua, gestão de projetos e tecnologia. O projeto oferece artigos aprofundados sobre SMT, PTH, core tools da qualidade, IoT, automação e muito mais.

## 📋 Visão Geral

O TechMounter Blog é uma aplicação web estática que carrega artigos dinamicamente a partir de arquivos JSON, proporcionando:

- **Carregamento dinâmico** de artigos via fetch API
- **Busca com filtros** por categoria
- **Paginação** com rolagem suave
- **Compartilhamento** em 5 redes sociais
- **Design responsivo** para desktop e mobile
- **Arquitetura escalável** para adicionar novos artigos facilmente

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estrutura semântica
- **CSS3** — Estilização com variáveis, grid, flexbox e media queries
- **JavaScript (ES6+)** — Lógica de carregamento, busca e navegação
- **JSON** — Armazenamento de conteúdo dos artigos
- **Font Awesome** — Ícones vetoriais
- **Google Fonts (Inter)** — Tipografia
